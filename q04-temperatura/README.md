# Questão 04 — Conversor de Temperatura

Aplicativo React Native (Expo) que converte entre Celsius e Fahrenheit.

## Funcionalidades
- Campo numérico e seleção do sentido (°C → °F ou °F → °C)
- Fórmulas: F = (C × 9/5) + 32 e C = (F − 32) × 5/9
- Exemplo: 30 °C → 86 °F

## Como executar
```bash
npx create-expo-app@latest q04-temperatura --template blank
cd q04-temperatura
# substitua o App.js pelo deste projeto
npx expo start
```
Abra com o **Expo Go** (QR code) ou cole o `App.js` em https://snack.expo.dev.
