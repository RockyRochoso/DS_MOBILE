# Questão 06 — Votação Estudantil

Aplicativo React Native (Expo) que registra votos para três candidatos fictícios.

## Funcionalidades
- Nome e botão **Votar** para cada candidato
- Total por candidato e total geral
- Indica o mais votado e informa empate na liderança (10, 15 e 8 → 2º candidato)
- Botão para zerar a votação

## Como executar
```bash
npx create-expo-app@latest q06-votacao --template blank
cd q06-votacao
# substitua o App.js pelo deste projeto
npx expo start
```
Abra com o **Expo Go** (QR code) ou cole o `App.js` em https://snack.expo.dev.
